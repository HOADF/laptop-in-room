# 💻 Laptop in Room

Творческая интерактивная сцена: ноутбук на столе с «живым» экраном. Идея проекта — ноутбук как окно для контента: внутри экрана работает мини-имитация рабочего стола со своим меню «Пуск», поиском и переключением страниц сайта, а на корпусе мигают диоды, создавая ощущение, что устройство активно работает.

🔗 [Посмотреть онлайн](https://hoadf.github.io/laptop-in-room/)
💾 [Исходный код](https://github.com/hoadf/laptop-in-room)

---

## 💡 О проекте

- экран ноутбука — не статичная картинка, а рабочая мини-ОС: окно с контентом, панель задач, меню «Пуск», поиск по разделам;
- переключение разделов «О нас / Услуги / Контакты» через панель задач, меню «Пуск» или поиск;
- на корпусе ноутбука — мигающие диоды (питание и активность диска) и индикатор веб-камеры над экраном, имитирующие «живую» работу устройства;
- 3D-перспектива комнаты, стол с мелкими предметами (органайзер, мышь);
- адаптивная вёрстка: на мобильных экранах сцена перестраивается без горизонтального скролла.

---

## 🧩 Технологии

- **HTML5** — структура сцены
- **CSS3** — 3D-перспектива, анимации диодов, адаптивность
- **JavaScript (Vanilla, ES-модуль)** — логика мини-ОС на экране ноутбука
